# RANOpt Roadmap

## Phase 1 — RAN Data & KPI Intelligence

Current phase.

- Typed KPI schema
- Validation
- Synthetic data
- Preprocessing
- Configurable thresholds
- Cell-health scoring
- Tests and CI foundation

## Phase 2 — Monitoring & Anomaly Detection

Planned:

- CSV/API ingestion improvements
- Rolling-window statistics
- KPI trend analysis
- Alert rules
- Anomaly detection
- Monitoring visualizations

## Phase 3 — Diagnosis & Optimization Recommendations

Planned:

- KPI correlation analysis
- Cell and neighbor analysis
- Problem classification
- Root-cause hypotheses
- Explainable optimization recommendations
- Recommendation confidence
- Simulation-based evaluation

## Phase 4 — AI Optimization

Planned:

- Cell-neighbor graph representation
- Optimization environment
- Baseline optimization methods
- Gymnasium environment
- PPO baseline
- Graph-based state representation
- Constraint-aware reward design
- Reproducible experiments
- Baseline and ablation comparisons

Results will only be reported after the corresponding experiments are actually executed.
